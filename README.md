# Three.js 物理和天文可视化项目集

这是一个使用 Three.js 开发的交互式 3D 可视化集合项目，旨在展示物理学概念和天文系统的工作原理。通过直观的 3D 模型和动画，帮助人们更好地理解抽象的科学概念。

## 项目概览

本项目集包含三个独立的可视化演示：

1. **太阳系 3D 模拟** - 交互式太阳系模型，展示行星运动和天体特征
2. **能量守恒定律可视化** - 通过小球在斜坡上的运动演示能量转换和守恒
3. **神经网络工作原理可视化** - 3D 展示神经网络的结构和信号传递过程

## 项目特点

- **高度交互性** - 所有演示都支持鼠标控制，可以自由调整视角
- **物理准确性** - 基于真实物理公式进行模拟计算
- **直观可视化** - 使用色彩、动画和标签清晰展示科学概念
- **中文界面** - 所有演示都提供中文标签和说明
- **精美渲染** - 使用阴影、光照、反射等效果增强视觉体验

## 技术实现

- **Three.js** - 主要的 3D 渲染引擎
- **JavaScript** - 用于实现动画和交互逻辑
- **HTML5/CSS3** - 提供页面结构和样式
- **物理计算** - 实现重力、动能、势能等物理模拟
- **OrbitControls** - 实现相机控制

## 使用指南

所有项目都可以通过点击上方表格中的演示链接直接访问。

基本控制方式：
- **左键拖动**：旋转视角
- **右键拖动**：平移视角
- **滚轮**：缩放视角
- **界面按钮**：提供额外的控制选项（如暂停/继续、重置等）

## 浏览器兼容性

所有演示都需要支持 WebGL 的现代浏览器。推荐使用最新版的 Chrome、Firefox、Safari 或 Edge。
