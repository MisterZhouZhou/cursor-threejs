# 能量守恒定律 3D 可视化

这是一个使用 Three.js 实现的能量守恒定律的 3D 物理演示。本项目展示了一个小球在坡道和地面上运动时，势能与动能之间的相互转换，以及能量守恒原理的直观展示。

## 功能特点

- 完整的物理模拟系统，包括重力、摩擦和碰撞
- 实时计算并显示势能、动能和总能量数值
- 动态能量条可视化能量变化
- 时间-能量图表直观展示能量转换过程
- 小球运动的轨迹可视化
- 可调节的物理参数（重力加速度、摩擦系数）
- 中文标签标注关键元素
- 使用阴影、高光、反射等效果增强视觉体验

## 物理原理

能量守恒定律是物理学中的基本定律之一，它指出在一个孤立系统中，能量的总量保持不变，只能从一种形式转化为另一种形式。在这个演示中：

- **势能(PE)** = mgh，其中m是质量，g是重力加速度，h是高度
- **动能(KE)** = 1/2 * mv²，其中m是质量，v是速度
- **总能量** = 势能 + 动能

在理想情况下，总能量应保持不变。但在现实模拟中，由于碰撞损耗和摩擦力，总能量会逐渐减少。

## 使用技术

- Three.js - 用于创建和渲染 3D 场景
- HTML5/CSS3 - 提供基本的页面结构和样式
- JavaScript - 实现物理计算、动画和交互逻辑

## 如何使用

1. 克隆或下载本项目到本地
2. 使用现代浏览器（如Chrome、Firefox）打开 `index.html` 文件
3. 交互控制:
   - 使用鼠标左键拖动旋转视角
   - 使用鼠标右键拖动平移视角
   - 使用滚轮缩放视角
   - 使用界面上的控制按钮和滑块调整模拟参数

## 控制面板功能

- **重置按钮**: 重新开始模拟，小球回到初始位置
- **暂停/继续按钮**: 暂停或继续模拟
- **重力加速度滑块**: 调整模拟中的重力大小（1-20 m/s²）
- **摩擦系数滑块**: 调整表面的摩擦系数（0-0.5）
