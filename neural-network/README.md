# 神经网络工作原理 3D 可视化

这是一个使用 Three.js 实现的神经网络工作原理的 3D 可视化演示。本项目展示了一个简化的神经网络模型，包括输入层、隐藏层和输出层，以及它们之间的连接和信号传递过程。

## 功能特点

- 完整的三层神经网络结构（输入层、隐藏层、输出层）
- 使用 3D 球体表示神经元节点
- 动态显示信号在神经元之间的传递过程
- 节点激活状态的可视化效果
- 交互式相机控制，可以从不同角度观察神经网络
- 使用阴影、高光、反射等效果增强视觉体验
- 中文标签标注各层功能

## 使用技术

- Three.js - 用于创建和渲染 3D 场景
- HTML5/CSS3 - 提供基本的页面结构和样式
- JavaScript - 实现动画和交互逻辑

## 如何使用

1. 克隆或下载本项目到本地
2. 使用现代浏览器（如Chrome、Firefox）打开 `index.html` 文件
3. 使用鼠标交互:
   - 左键拖动: 旋转视角
   - 右键拖动: 平移视角
   - 滚轮: 缩放视角

## 演示内容说明

- **蓝色节点**: 表示输入层神经元
- **红色节点**: 表示隐藏层神经元
- **绿色节点**: 表示输出层神经元
- **黄色连线**: 表示激活状态的连接
- **灰色连线**: 表示非激活状态的连接
- **移动的球体**: 表示神经网络中传递的信号
