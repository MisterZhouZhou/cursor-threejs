# 太阳系3D模拟

一个使用Three.js实现的交互式太阳系3D模拟器。

## 功能特点

- 太阳系八大行星的3D模拟，包括太阳、水星、金星、地球、火星、木星、土星、天王星和海王星
- 真实的行星纹理和相对比例
- 行星的自转和公转动画
- 地球带有月球和大气层效果
- 土星带有光环效果
- 太阳发光效果
- 行星标签（中文）
- 星空背景
- 轨道控制，支持缩放、旋转和平移视角
- 动画控制（暂停/继续、重置视角）

## 使用说明

1. 打开`index.html`文件即可运行模拟器
2. 使用鼠标控制视角：
   - 左键拖动：旋转视角
   - 右键拖动：平移视角
   - 滚轮：缩放视角
3. 界面上的按钮：
   - 暂停/继续：控制太阳系动画的暂停和继续
   - 重置：将视角重置为初始位置

## 技术实现

- 使用Three.js作为3D图形引擎
- 使用原生JavaScript实现动画和交互
- 使用OrbitControls实现视角控制
- 使用真实的行星纹理
- 实现阴影、高光和大气层效果
- 使用HTML Canvas创建行星标签
